# 回测与因子验证

判断信号有没有 edge 的**唯一**手段。底层 `finbot.backtest`。

## 用法
```bash
finbot update --date 2026-06-02      # 先有数据仓库
finbot backtest --h 5                # 回测：用因子合成分作为基线信号
finbot backtest --h 5 --source mock  # 离线演示
```

## 输出怎么读
- **ic_summary**：`ic_mean` 是核心——**现实里稳定在 0.03–0.08 即良好**；`t_stat`>2、
  `hit_rate`>0.5 才说明 IC 显著为正、稳定。
- **quantile_returns**：Q1→Q5 的前瞻超额收益应**单调递增**，且 Q5>Q1>0 才说明信号能排序未来收益。
- **performance**：含摩擦后的年化、夏普、最大回撤、胜率。

## 摩擦（已建模）
- **T+1**：标签按次日收盘建仓计算。
- **封板不可买入**：建仓日涨幅≈涨停的标的被剔除（买不进）。
- **成本**：每期换手 × 往返成本（佣金+印花税+滑点）。
- 建议 `rebalance_days == H`，保证周期不重叠、无偏。

## ⚠️ 纪律
- **mock 数据的回测结果无意义**（随机数据），只能验证流程；要看 edge 必须用真实数据。
- 新因子必须证明**相对已有因子有增量 IC** 才保留，否则删除——防过拟合。
- 回测乐观于真实滑点/排队；实盘前务必小资金验证。回测好≠未来赚钱。
