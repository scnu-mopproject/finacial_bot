# 更新本地数据仓库

把行情、基础信息、基准指数、跨资产宏观（商品/外汇/利率）、新闻**增量**落到本地
（`data/warehouse/`，git 忽略），后续所有分析与回测都从本地读，毫秒级。

## 用法
```bash
# 首次：自动回填历史（默认 250 个交易日）
finbot update --date 2026-06-02

# 之后每日：只增量补最近几天（默认 10 天，便宜快速）
finbot update --date 2026-06-03

# 只看仓库现状（每张表多少行、更新到哪天），不拉数据
finbot update --status

# 离线/演示用确定性 mock 数据
finbot update --date 2026-06-02 --source mock
```

## 仓库里有什么（长表）
- `daily_bar`：个股日线 OHLCV
- `daily_basic`：名称/板块/成交额/换手率/是否 ST（每日快照）
- `index_bar`：基准指数（默认中证全指 000985）
- `macro`：跨资产宏观——USD/CNY、USD/CNH、DXY、商品、利差
- `news`：财经新闻

## 注意
- 每张表有**水位（watermark）**记录更新到哪天，增量更新只补缺失日期、并按主键去重。
- 真实数据走 AkShare；失败自动回退 mock，不会中断。
- 首次回填会对全市场逐只拉历史（较慢，仅一次）；之后增量很快。
- 仓库数据**不提交 git**。
